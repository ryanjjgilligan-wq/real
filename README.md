# LuxePatron

A high-ticket, invitation-only subscription platform connecting discerning
patrons with the world's most coveted creators, operators, artists, and
thought leaders. Memberships begin at $500/month and reach $45,000+/yr.

## Stack

- Next.js 15 (App Router, RSC) on Vercel
- TypeScript
- Tailwind CSS
- Mock checkout API ready to swap for Stripe Billing

## Local

```bash
npm install
npm run dev
```

## Production

Hooked into Vercel for one-click deploys. Domain: **luxepatron.com**.
